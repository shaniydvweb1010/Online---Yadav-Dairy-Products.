# Online--Yadav-Dairy-Products.
# http://localhost/yadav-dairy/

**Yadav Dairy Farm** is an online dairy products and milk delivery website designed to provide fresh milk and dairy products directly to customers.

## 🚀 Features

* 🥛 Fresh Milk Products
* 🧀 Dairy Products
* 🛒 Online Product Ordering
* 🚚 Home Delivery
* 👤 Customer Registration & Login
* 📦 Order Management
* 📱 Responsive Design
* 🗄️ Database Integration

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* PHP
* MySQL

## 📂 Project Structure

```text
yadav-dairy-farm/
│
├── index.php
├── products.php
├── cart.php
├── checkout.php
├── login.php
├── register.php
├── admin.php
├── css/
├── js/
├── images/
└── database/
```

## 🎯 Project Objective

The main objective of this project is to create a simple and user-friendly online platform where customers can browse dairy products, place orders, and get fresh products delivered to their homes.

## 💻 Local Setup

1. Install **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Copy the project folder into the `htdocs` folder.
4. Create the required MySQL database.
5. Import the project SQL file into **phpMyAdmin**.
6. Open the project in your browser.

```text
http://localhost/yadav-dairy/
```
